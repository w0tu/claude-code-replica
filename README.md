# Claude Code Replica - Final Release 🚀

Welcome to the ultimate terminal-based agentic coding assistant! This tool provides a powerful alternative to Claude Code, built for the long run.

## Features

- **Rate Limit Protection**: Built-in intelligent delay to handle API limits without cluttering UI.
- **Enhanced Visuals**: Beautiful matching box with animations for `/` commands and `@` file mentions.
- **Syntax Highlighting**: Real-time syntax formatting (using Monokai theme) directly in your terminal.
- **Super Thinking**: Expandable thought chain rendering with bold highlights for "super thinking" mode.
- **Usage Heatmap**: Type `/usage` to view a GitHub-style 32-square heatmap of your monthly usage.
- **Clean UI**: Removed verbose AI tags to provide a clean, developer-focused prompt box at the bottom.

## Usage

Simply run:
```bash
python -m claude_replica.cli
```

### Commands

- `/usage` - Show monthly usage heatmap
- `/model` - Switch models
- `@filename` - Autocomplete project files
- `/help` - Show all commands
